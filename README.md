# AI 도감 스튜디오

**👉 바로 쓰기: https://arongstar.github.io/ai-dogam-studio/**

학생들이 **사진으로 이미지 분류 AI를 직접 가르치고, 시험하고, 고쳐서** 동생들(사용자)을 위한 AI 도감으로 내놓는 초등 8차시 AI 융합 프로젝트용 웹앱입니다. 회원가입·서버가 없고, 사진과 기록은 학생 기기 안에만 저장됩니다.

- 주제 3가지: 🌿 식물 도감 · ♻️ 분리배출 도우미 · 🔎 직접 정하기(곤충, 돌 등)
- 학급 링크·QR로 학생 참여, 차시별 4자리 열기 코드
- 한 번 열면 인터넷 없이도 사용 가능 (홈 화면에 앱으로 설치 가능)
- 판단 기록 CSV, 교사 대시보드, 모둠 포트폴리오 인쇄

## 선생님: 5분 시작하기

1. 앱 주소를 열고 **[＋ 학급 만들기]**를 누릅니다. 처음 한 번은 교사용 비밀번호를 정합니다.
2. 반, 주제, 모둠 수를 정하면 **학생용 QR 코드와 링크**가 나옵니다. [학생용 안내문 인쇄]로 나눠 주거나 화면에 띄우세요.
3. 학생은 QR을 찍고 **모둠 번호만** 고르면 됩니다.
4. 수업마다 그 차시의 **열기 코드**(학급 화면의 ② 칸)를 칠판에 적어 주세요. 학생이 잠긴 차시를 누르고 코드를 넣으면 열립니다.
5. 차시가 끝나면 모둠마다 **[💾 파일로 저장]**을 하게 하세요. 파일을 모아 **[교사 대시보드]**에 불러오면 진행 상황을 한눈에 볼 수 있습니다.

앱 안의 **[📘 교사 안내]**에 차시별 흐름, 주제별 연계 성취기준(2022 개정), 개인정보 안내가 있습니다.

## 준비물

- 모둠당 카메라가 있는 태블릿·크롬북 1대 (최신 크롬·엣지·사파리)
- 처음 한 번 인터넷 연결: AI 모델(약 14MB)을 받아 기기에 저장합니다.
- 관찰할 실물 (식물 잎, 깨끗이 씻은 재활용품 등)

## 개인정보와 안전

- 사진·기록은 학생 기기의 브라우저(IndexedDB)에만 저장되고 어떤 서버로도 보내지 않습니다.
- 학급 링크에는 반 이름, 주제, 모둠 수, 열기 코드용 값, 교사 비밀번호의 해시만 담깁니다. 학생 정보는 담기지 않습니다.
- 사람 얼굴은 찍지 않도록 지도하고, 모둠원 이름은 번호나 별명을 권장합니다.
- 교사 비밀번호와 열기 코드는 교실용 잠금 장치입니다. 시험 문제처럼 중요한 정보를 지키는 보안 장치는 아닙니다.

## 배포하기 (다른 학교와 함께 쓰기)

카메라를 바로 켜려면 **https 주소**가 필요합니다. 이 폴더의 파일을 그대로 정적 호스팅에 올리면 됩니다. 빌드 과정은 없습니다.

| 방법 | 순서 |
| --- | --- |
| GitHub Pages | 저장소에 이 폴더의 파일을 올림 → Settings → Pages → Branch: `main` / `/(root)` → 저장. 몇 분 뒤 `https://아이디.github.io/저장소이름/` 주소가 생깁니다. |
| Netlify Drop | app.netlify.com/drop 에 이 폴더를 끌어다 놓으면 주소가 생깁니다. |
| 교사 컴퓨터에서 시험 | 이 폴더에서 `python -m http.server 8765` 실행 → `http://localhost:8765` |

새 버전을 올릴 때는 `sw.js`의 `VERSION` 값을 바꿔 주세요. 학생 기기가 새 파일을 받습니다.

## AI는 어떻게 판단하나요?

1. MobileNet v2가 사진에서 특징(숫자 1,280개)을 뽑습니다.
2. 항목마다 가장 닮은 학습 사진 3장과의 평균 유사도를 구해, 가장 닮은 항목으로 판단합니다.
3. **확신도** = 항목끼리의 차이(소프트맥스) × 학습 사진과의 익숙함. 학습하지 않은 것을 보여 주면 '처음 보는 것'이 커지고 확신도가 낮아집니다.

`app.js`의 `SIM_TEMP`, `FAM_LO`, `FAM_HI`로 확신도 계산을 조정할 수 있습니다. 실제 사진에서 맞는 답인데도 확신도가 지나치게 낮으면 `FAM_LO`·`FAM_HI`를 조금 낮추세요.

## 주제 추가하기

`app.js` 위쪽의 `TEMPLATES`에 항목을 하나 추가하면 새 주제가 생깁니다. 특징 항목(`features`), 도감 카드 항목(`card`), 약속(`rules`), 동생 모드 문구, 연계 성취기준(`standards`)을 정할 수 있습니다.

## 알려진 한계

- 실제 사진으로는 아직 충분히 확인하지 않았습니다. 수업 전에 실물 3~4가지로 미리 써 보세요.
- 모둠 기록을 모으는 기능은 파일 방식입니다(서버가 없기 때문).
- '읽어 주기' 목소리는 기기에 설치된 한국어 음성에 따라 다릅니다.

AI 모델: Google MobileNet v2 (TensorFlow.js, Apache-2.0)
